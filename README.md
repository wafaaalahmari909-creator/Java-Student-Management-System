# Java-Student-Management-System
A Java-based Student Management System developed as an academic project using JavaFX and Maven.

## Overview
The application provides a graphical interface for managing student records and academic grades. It includes features for adding students, entering grades, viewing student information, and generating reports.

## Features
- User login interface
- Add and manage student records
- Enter and manage student grades
- View student information
- Generate academic reports

## Technologies Used
- Java
- JavaFX
- FXML
- Maven
- NetBeans IDE

## Project Type
Academic Project
